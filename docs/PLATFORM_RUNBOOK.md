# AICore 全平台运行保障清单（Runbook）

> 结论先行：当前仓库已完成“可开发骨架 + 关键策略实现”，尚未达到“所有平台功能全部实现并完成真机验证”的发布态。

## 1. 当前实现状态

- ✅ 已实现：
  - 模块化分层与契约边界（core/feature）。
  - 会话恢复 + 离线缺失自动降级云端。
  - Web 禁离线策略校验。
  - 移动端下载约束（WiFi + 充电 + 1.5x 空间校验）逻辑。
- ⏳ 待实现：
  - Compose Multiplatform UI 页面与导航。
  - 平台原生能力接入（ASR、文件选择器、快捷键、拖拽）。
  - 真机/模拟器 CI 与发布打包流水线。

## 3. 保证全平台正常运行的执行步骤

1. **构建层**：补齐 `androidTarget/ios*/wasmJs` 目标与平台 sourceSet。
2. **能力层**：实现 `expect/actual` 平台适配（文件、语音、网络状态、电源状态、存储空间）。
3. **测试层**：
   - 单元测试：契约、降级、策略。
   - 集成测试：模型切换、下载中断恢复、消息流式一致性。
   - UI 测试：窗口尺寸断点与三栏布局。
4. **发布层**：
   - Android APK/AAB
   - iOS TestFlight
   - Desktop 安装包
   - Web 部署包

## 4. 下一步（建议 2 周内）

- Week 1：完成 KMP 多目标配置 + 平台能力 expect/actual 接口。
- Week 2：实现 Chat + Settings 最小 UI 闭环并跑通 Android/iOS/Desktop/Web 冒烟测试。
