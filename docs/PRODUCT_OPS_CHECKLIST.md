# AICore 产品负责人执行清单（推进与运行保障）

## 1. 周节奏（必须执行）

- 周一：确认里程碑偏差、冻结本周范围。
- 周三：跨端风险同步（Android/iOS/Web/Desktop）。
- 周五：演示 + 文档审查 + 风险清零计划。

## 2. 需求与变更控制

- 需求基线：`PRD_V3.0.md`。
- 新需求进入标准：
  1. 是否影响“单页问答”主路径。
  2. 是否破坏模块契约边界。
  3. 是否引入跨平台行为不一致。
- 通过后动作：更新 PRD、更新交付计划、补充 ADR。

## 3. 研发过程关键看板

- 功能完成率（按 P1~P5）
- 阻塞项 SLA（超 48h 必须升级）
- 缺陷趋势（新增/关闭/回归）
- 性能达标率（首 Token 延迟、内存增量）

## 4. 验收门禁（Go/No-Go）

- 体验门禁：
  - 主路径“输入 -> 流式回复 -> 操作消息”稳定可用。
  - 在线/离线切换无崩溃、状态可解释。
- 技术门禁：
  - `feature:chat` 未依赖具体引擎实现。
  - 冷启动降级逻辑全链路可复现。
- 文档门禁：
  - 每个阶段有测试报告和风险结案记录。

## 5. 发布运行保障

- 监控指标：启动成功率、首 Token 延迟、崩溃率、下载成功率。
- 灰度策略：
  - 先 Desktop，再 Android/iOS，最后 Web。
  - 关键异常触发自动回滚与公告模板。
- 应急预案：
  - 供应商 API 故障 -> 默认切换备选供应商。
  - 离线模型损坏 -> 触发重新校验与自动降级。
