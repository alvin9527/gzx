# AICore 关键逻辑归档（ADR）

> 本文档用于沉淀“为什么这样设计”，保障团队在模块替换、跨平台适配和故障排查时有可追溯依据。

---

## ADR-001：以 `:core:session-manager` 作为全局唯一配置源

- 状态：Accepted
- 日期：2026-04-15

### 决策
所有模块读取运行态配置时必须经过 `SessionManager` 聚合输出，不允许各模块直接读取本地配置并自行推断。

### 背景
多模块并发初始化容易出现配置不一致（例如模型已删除但角色仍绑定）。

### 结果
- 冷启动可统一做可用性校验和能力校验。
- 降级策略可集中实现并复用。

---

## ADR-002：`feature:chat` 与推理实现强解耦

- 状态：Accepted
- 日期：2026-04-15

### 决策
`feature:chat` 仅依赖 `InferenceEngine` 契约，不得导入 LiteRT 或 ONNX 实现包。

### 背景
聊天界面需支持多引擎快速替换与独立 UI 验证。

### 结果
- UI 可使用 Mock ViewModel 独立测试。
- 引擎替换不会触发 UI 重构。

## ADR-003：引擎切换时保留历史气泡、清空 KVCache

- 状态：Accepted
- 日期：2026-04-15

### 决策
在线/离线或模型切换时，确认后保留可见聊天历史，清空推理上下文缓存。

### 背景
用户希望保留可读历史，同时避免跨模型上下文污染。

### 结果
- 兼顾体验连续性与生成稳定性。
- 明确“可见历史 ≠ 推理上下文”产品语义。

---

## ADR-004：Web (Wasm) 仅支持在线模式

- 状态：Accepted
- 日期：2026-04-15

### 决策
Web 端隐藏并禁用离线模型下载与加载能力。

### 背景
Wasm 在本项目目标形态下不具备稳定离线大模型运行条件。

### 结果
- 降低前端复杂度与失败率。
- 对外能力口径更清晰。

---

## ADR-005：离线模型下载前强制 1.5x 空间校验

- 状态：Accepted
- 日期：2026-04-15

### 决策
下载前必须校验剩余空间 >= 模型大小的 1.5 倍，移动端额外要求 WiFi + 充电。

### 背景
大文件下载失败与中断恢复会产生临时文件与重复写入。

### 结果
- 显著减少下载失败与磁盘写满导致的异常。
- 保护移动端电池与用户流量成本。
